# Web TastyPoll
Mediante el link compartido de la [aplicación](https://github.com/DesertFernanfer/TastyPoll/releases/tag/%23TastyPoll) permite entrar y votar el alimento que
quieras filtrando por nombre, categoría y permite meter el email en caso de lo requiera para recibir los reusltados por email.


## 🚀 Tecnologías

- **Frontend Web:** JavaScript / HTML / CSS / Firebase Hosting
- **Backend:** Node.js / JavaScript / Firebase functions
